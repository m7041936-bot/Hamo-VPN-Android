# Hamo VPN — Android starter

هذه نسخة بداية لمشروع أندرويد باسم Hamo VPN.

## الموجود
- واجهة عربية بسيطة.
- طلب إذن Android VPN.
- اختيار ملف إعدادات من الجهاز.
- خدمة VpnService فارغة كنقطة دمج.

## غير الموجود بعد
- محرك WireGuard أو SSH أو OpenVPN.
- الاتصال بسيرفر.
- توليد إنترنت أو تجاوز رسوم شركة الاتصالات.

**مهم:** التطبيق الحالي نموذج أولي وليس VPN عاملًا، ولن يفتح الإنترنت بمجرد تثبيته. يلزم دمج محرك VPN موثوق وإعداد سيرفر تملك صلاحية استخدامه، مع اتصال إنترنت قائم ومسموح به.

## البناء
افتح المجلد في Android Studio حديث ثم Build > Build APK(s).
يتطلب Android SDK 35 ونسخ Gradle/Android Gradle Plugin المتوافقة.
